# Reader: data:locomo

LOCOMO FOR A LOADER/SCORER (all verified against the downloaded file and the repo code)

Download: https://raw.githubusercontent.com/snap-research/locomo/main/data/locomo10.json (branch main; 2,805,274 bytes; sha256 79fa87e90f04081343b8c8debecb80a9a6842b76a7aa537dc9fdf651ea698ff4). Repo README is README.MD (uppercase), licence file LICENSE.txt = Creative Commons Attribution-NonCommercial 4.0 (paper App. B.2: CC BY-NC 4.0 DEED). Images are not released (only img_url, blip_caption, icrawler query).

Schema: top level is a JSON list of 10 objects with keys sample_id (conv-26, -30, -41, -42, -43, -44, -47, -48, -49, -50), conversation, qa, observation, session_summary, event_summary. conversation = {speaker_a, speaker_b, session_N: [turn...], session_N_date_time: "1:56 pm on 8 May, 2023"} (parse with "%I:%M %p on %d %B, %Y"; all 288 strings match). Sessions are contiguous 1..K and dates strictly increase; conv-26 carries orphan session_20..35_date_time keys with no session_20..35, so iterate over session_N keys, not date_time keys. Turn = {speaker, dia_id, text} plus optional img_url (always a 1-element list), blip_caption, query, re-download (True). dia_id is "D{session}:{turn}", 1-indexed, prefix always equals the session number (0 mismatches/5,882). Counts: 10 conversations, 272 sessions (19–32/conv), 5,882 turns (369–689/conv; 10–47 per session, mean 21.6), 1,226 caption-bearing turns (910 with URLs), 1,986 QA, 2,541 observations, 669 event entries; ~200K cl100k tokens of "speaker: text [+caption]" (≈20K/conv; ACL Table 5 reports 16,618 tokens/conv, 27.2 sessions, 21.6 turns/session). Date spans 166–293 days per conversation. Speaker names repeat across conversations ("John" in 3), so key entities by (sample_id, name).

QA record = {question, answer, evidence: [dia_id...], category: int}. answer is a string except 6 ints (e.g. 2022) -> str() it. Category 5 (446) has adversarial_answer (the trap answer) and NO answer key in 444/446 (2 have both). evidence: 4 empty lists; 6 malformed strings ('D8:6; D9:17', 'D', 'D:11:26', space-separated lists); 3 dangling ids (conv-42 D10:19, conv-47 D4:36, conv-50 D30:05). Evidence distribution: 1,559 single-id, 427 multi-id; 1,064/2,815 evidence refs point at caption-bearing turns.

CATEGORY INTEGERS — THE CENTRAL TRAP. The paper's prose lists categories as (1) single-hop ... (5) adversarial, but the data and the official code use: 1 = multi-hop (282), 2 = temporal (321), 3 = open-domain/commonsense (96), 4 = single-hop (841), 5 = adversarial (446). Evidence: ACL Table 5 counts; task_eval/evaluation.py scores category 1 with the comma-split "multi-hop" F1 and categories 2/3/4 with plain F1 ("single-hop, temporal, open-domain"); evaluation_stats.py prints in order [4,1,2,3,5] = the Table 2 column order Single/Multi/Temporal/Open/Adversarial; the A-MEM reproduction README states the same mapping; content heuristics agree (83% of cat-2 questions start "When/How long"; 98% of cat-1 have >=2 evidence ids; 44% of cat-3 contain would/likely).

OFFICIAL SCORER (task_eval/evaluation.py): normalize_answer = drop commas, lowercase, strip punctuation, remove a/an/the/and; tokens Porter-stemmed; multiset-overlap F1. Cat 1: split prediction and gold on ','; score = mean over gold sub-answers of max F1 over predicted sub-answers. Cat 2/3/4: plain F1; cat 3 gold truncated before the first ';' (11 cat-3 golds carry alternatives). Cat 5: 1 if 'no information available' or 'not mentioned' in output.lower() else 0; the official prompt turns cat 5 into a 2-option MC "(a) Not mentioned in the conversation (b) {trap answer}" (code reads qa['answer'], which the released file names adversarial_answer). Cat-2 questions get the suffix "Use DATE of CONVERSATION to answer with an approximate date." Overall = mean over all 1,986 including cat 5. Published F1 (ACL Table 2, order single/multi/temporal/open/adv/overall): human 95.1/85.8/92.6/75.4/89.4/87.9; gpt-4-turbo 72.3/51.5/51.4/38.5/15.7/51.6; RAG gpt-3.5 + DRAGON dialog top-25 59.9/38.7/37.2/25.0/12.8/41.0.

Generated fields: observation[session_N_observation] = {speaker: [[text, dia_id], ...]} produced by gpt-3.5-turbo with CONVERSATION2FACTS_PROMPT + in-context examples (prompt_examples/fact_generation_examples_new.json), which asks for objective facts with the supporting dia_id (7 items carry multiple ids). session_summary[session_N_summary] is a gpt-3.5-turbo (temp 1.0, 256 tokens) summary "using exact words... all facts about the two speakers, as well as references to time". event_summary[events_session_N] = {speaker: [events], date} is human-annotated ground truth for event summarisation.

MEM0 'J' PROTOCOL (code at mem0ai/mem0@aae5989, copied verbatim by Memobase and Zep): judge gpt-4o-mini, temperature 0, JSON mode, lenient prompt adapted from MemGPT ("as long as it touches on the same topic... CORRECT"); category 5 skipped -> 1,540 questions; answer model gpt-4o-mini; F1 is A-MEM's set-based, unstemmed, no article removal, no comma split (not the official metric); BLEU-1 via nltk with smoothing; paper reports mean±sd over 10 judge runs. Mem0's generate_scores.py prints by integer only; names were attached when writing the paper as 1→Single-hop, 2→Temporal, 3→Multi-hop, 4→Open-domain (explicit in the Memobase fork; Mem0's overall 66.88 reproduces exactly only under that mapping; Mem0's Table 1 also relabels A-MEM's published columns accordingly).

WHY NUMBERS ARE NOT COMPARABLE — five label conventions coexist: (A) official/A-MEM/Kumiho/Nemori 1=multi,2=temporal,3=open,4=single; (B) Mem0 harness (Mem0, Memobase, Backboard/Hindsight, Memory-R1) 1=single,2=temporal,3=multi,4=open; (C) MemoryOS 1=single,2=multi,3=temporal,4=open (its table relabels A-MEM/MemGPT numbers that way); (D) Zep README 1=multi,2=open,3=temporal,4=single (recomputed from Zep's grades file: cat1 74.11, cat2 66.04, cat3 67.71, cat4 79.79, overall 75.13); (E) Memobase's "Zep*" row, copied into Hindsight, 1=single,2=multi,3=open,4=temporal. Only overall scores are label-invariant. Metrics also differ: official stemmed F1 incl. adversarial (LoCoMo, Kumiho), set-based F1/BLEU-1 (A-MEM, MemoryOS, Memory-R1), gpt-4o-mini judge (Mem0, Zep, Nemori, LightMem, Memobase), GPT-OSS-120B judge (Hindsight), Qwen3-14B strict judge (LoCoMo_refined: Mem0 48.91). Kumiho's README states judge accuracy inflates scores 1.5–2x over token F1 and that unpinned gpt-4o drifted (0.565 -> 0.531 reproducible).
