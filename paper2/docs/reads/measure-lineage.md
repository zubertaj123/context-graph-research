MEASURE LINEAGE NOTES (all formulas in ASCII; "verified" = I read the text myself from the fetched PDF/HTML).

1) al-Saffar & Heileman, iiWAS 2010 (PDF read via pdftotext; pp. 347-354). Inputs: target graph Gt (semantics of the candidate information), context graph Gc (consumer's world-view); output SIV(Gt,Gc) in [0,1]. Actual value: SIVa(Gt,Gc) = DeltaGc (1); Gc' = l(Gc,Gt) (2) where l is "some learning function representing the set of inference rules through which the information consumer may learn from assertions in Gt and generate new assertions to update Gc" (two cases: l known so Gc' is derived by automated reasoning, or Gc' is given); SIVa = DeltaGc = disSimilarity_a(Gc,Gc') (3); dissimilarity = 1 - similarity (4); disSimilarity_a(Gc,Gc') = (|Ec'| - |Ec|) / |Ec'| (5), |Ec| = edges of Gc, |Ec'| = edges of Gc' PLUS the number of Gc edges whose labels changed; assumption "knowledge does not decrease" so revisions are label changes, never deletions; uniform edit costs; isomorphism is linear because graphs are labeled. Predicted value: Gc' = Gt UNION Gc (6); disSimilarity_p(Gc,Gc') = (SUM_{i=1..n} w(e'_i) - SUM_{i=1..m} w(e_i)) / SUM_{i=1..n} w(e'_i) (7) with w(e'_uv) = t*degree(v) if u in Gt and v in Vc∩Vt; w(e'_uv) = t*degree(u) if v in Gt and u in Vc∩Vt; w(e'_i) = 1 otherwise; t = Trust. Trust(Gt,Gc) = |Et ∩ Ec| / |Et| (8) (Def. 2 "degree of agreement"; normalised by |Et| so asymmetric; "ten statements ... agree with eight ... trust is 80 percent"). Impact(Gt,Gc) = SUM_i d_i / SUM_i d'_i (9), d_i = degree in Gc of v_i in Vc∩Vt, d'_i = degree in Gc of every v_i in Vc (i.e. share of Gc's total degree sitting on overlapping vertices). SIVp = f(Impact,Trust) (10), "We use multiplication." Disconnected/cold-start case: if Gt shares no vertices with Gc, Gc' differs only by a new disconnected component whose added edges get cost 1 (so (7) reduces to a new-edge ratio, while (10) gives 0 because Trust=0 - the paper does not reconcile (7) and (10) beyond saying (7) is "a particular weights assignment"). Scalability: only linear-time ops. Evaluation: NONE quantitative - a Firefox plug-in + Java servlet + DBpedia-in-Virtuoso prototype; Gt built by matching rdf:label literals; authors state edges (relations) are hard to extract and that "human-based survey evaluation techniques may be required". No code published (author page lists only PDFs).

2) 2008 predecessors. DocEng'08 "Semantic impact graphs for information valuation" (DOI 10.1145/1410140.1410181, pp. 209-212) and IEEE IS'08 "Semantics-based information valuation" (DOI 10.1109/IS.2008.4670438, pp. 651-658) are closed access (ACM 403, S2 status CLOSED); abstracts obtained from the Arizona experts pages. Trust there was NOT agreement-based: iiWAS 2010 Sec. 4.2.1 states "In our previous work we required the consumer to explicitly (maybe with the help of an assisting application) specify degrees of trust they have in the provenance of the information source of Gt [3]", using "a special kind of graph" (semantic impact/causal graphs) rather than plain RDF.

3) Knowledge Vault (KDD 2014) and KBT (arXiv 1502.03519). KV fuses extractors with a per-predicate boosted-decision-stump classifier over a feature vector holding, per extractor, sqrt(#sources that produced the triple) and the mean extractor score (footnote: sqrt(n) damps "very commonly expressed facts"; log(1+n) similar); Platt scaling; labels from the Local Closed World Assumption. Graph priors: PRA (random-walk path features + logistic regression, AUC 0.884) and an MLP Pr(G(s,p,o)=1) = sigma(beta^T f(A [u_s, w_p, v_o])), L=K=60, AUC 0.882; fused priors AUC 0.911; prior+extractor raises triples with p>=0.9 from ~100M to ~271M (33% new vs Freebase); Table 5 AUC prior 0.943 / extractor 0.872 / both 0.959 (LCWA labels). KV has no per-source trust term. KBT defines source trust as accuracy A_w = P(a value w provides is correct); single-layer ACCU: p(X_sdv=1|V_d=v*,A_s) = A_s if v=v*, (1-A_s)/n otherwise (n = #false values), EM with A_s init 0.8 and M-step A_s = mean posterior probability of the facts s provides (eq 4). Multi-layer: C_wdv (w really provides (d,v)), X_ewdv (e extracted it), extractor recall R_e and false-positive rate Q_e = gamma/(1-gamma) * (1-P_e)/P_e * R_e; presence vote Pre_e = log R_e - log Q_e, absence vote Abs_e = log(1-R_e) - log(1-Q_e); p(C_wdv=1|X) = sigma(VCC + log(alpha/(1-alpha))); value vote VCV(w) = log(n A_w/(1-A_w)); p(V_d=v) = softmax of summed votes; KEY EQUATION (28): A_w = SUM p(C_wdv=1|X) p(V_d=v|X) / SUM p(C_wdv=1|X). Applied to 2.8B triples; 119M webpages/5.6M websites get KBT; KBT "almost orthogonal" to PageRank.

4) RELIN (ISWC 2011, full PDF read): random surfer with relational move M and informational jump J; x(t+1) = (M*Delta + J*Lambda) x(t), Delta_qq = 1-lambda, Lambda_qq = lambda; M_pq ∝ Rel(Prop(fp),Prop(fq))*Rel(Val(fp),Val(fq)) with Rel = PMI(si,sj) = log(P(si,sj)/(P(si)P(sj))), probabilities = Google Hits/N; informativeness SelfInfo(o) = -log P(o) (7), P(fp|fq) = |{e: fp,fq in FS(e)}| / |{e: fq in FS(e)}| (8), J_pq = -log P(fp|fq) (9), approximable by SelfInfo(fp). 10 iterations; lambda in {0,0.15,0.5,0.85,1}; best lambda=0.85 (k=10) / 1.0 (k=5). The 2021 survey (same group) restates si(<p,v>) = -log |{e': <e',p,v> in Desc(e')}|/|E| (eq 12) and pr(t) = (1-d) pJ(t) + d SUM pr(t') pM(t',t) (eq 20) but prints PMI without the log. SDType (ISWC 2013, read): conf(T(r)) = nu * SUM_p w_p P(T(r)|exists p.(r)), w_p = SUM_t (P(t) - P(t|exists p.))^2, nu = 1/SUM_p w_p; thresholds 0.4-0.6 give precision 0.95-0.99. SDValidate (IJSWIS 2014) original unreachable (IGI 429, author host redirects, archive.org blocked); Paulheim's own later text: per-property object-type distribution, score = deviation of o's types from p's distribution, low score = faulty.

5) W3C Delta (Berners-Lee & Connolly, 2001/2004, ns http://www.w3.org/2004/delta#): ground delta = (insertions = G2-G1, deletions = G1-G2); weak vs strong delta; strong delta = set differences of functional analogs F1,F2 of fully labelled graphs (bnodes labelled via owl:FunctionalProperty / owl:InverseFunctionalProperty paths); terms diff:replacement, diff:insertion, diff:deletion; insertion/deletion form implemented in cwm.

6) GAM (arXiv 2604.12285): Eq. 2 b_t = I(Delta(G_event, G_topic) > epsilon), "b_t = 1 signifies a structural shift requiring consolidation"; Delta is never defined; Sec. 3.3: computing Delta "is computationally expensive and sensitive to lexical noise", so an LLM boundary prompt is used and "the instruction strictness of the semantic discrimination prompt acts as a heuristic proxy for epsilon"; check fires on SessionEnd or buffer > T_max = 2048 tokens; merge = summary node, top-K=5 topic candidates, LLM relation confidence w > tau (tau unspecified).

7) Fei et al. (arXiv 2606.12290): selectors s(i) = g(c(i,Q), sigma(i;G,Q)); reliance S_dom = 1 - Jaccard(top-k(G), top-k(G-)); Criterion 1 (accumulability): divergence set non-empty only if (a) reallocatability - a no-source structural write can divert an Omega(1) share of what determines top-k membership onto nodes outside every returned item's derivation closure - and (b) that share exceeds the selected target's anchoring margin; "Reliance is not the criterion; accumulability is." PPR satisfies (a) always; per-item selectors and content-fixed rerankers fail (a). Table IV: B-SLM "Bayesian trust (post)" harm .0537 = no-defense, 18/18 blind rows; B-AMemGuard consensus self-check .0537; B-Rerank .078; AuthSelect .000. B-SLM is a re-implementation of SuperLocalMemory (arXiv 2603.02240): t_{i+1} = t_i + delta * 1/(1 + n*eta), eta = 0.01, t_0 = 1.0 (eval uses Beta(2,1), 0.667), signals +0.015/+0.01/+0.02 and -0.02/-0.03/-0.025, write/delete blocked below 0.3 - note it is per-AGENT trust, additive, not a Beta posterior per memory.

- [verified] iiWAS 2010 eq (1)-(3): SIVa(Gt,Gc) = DeltaGc; Gc' = l(Gc,Gt) where l is 'some learning function representing the set of inference rules through which the information consumer may learn from assertions in Gt and generate new assertions to update Gc'; SIVa = disSimilarity_a(Gc,Gc'). Two computable cases: l is known (automated reasoning) or Gc' is given.  
  source: https://hpc.pnl.gov/people/sinan/publications/al-Saffar_InfValue-iiWAS10.pdf
- [verified] iiWAS 2010 eq (5): disSimilarity_a(Gc,Gc') = (|Ec'| - |Ec|) / |Ec'| in [0,1]; |Ec| = number of edges in original Gc; |Ec'| = number of edges in revised Gc' + number of edges in Gc that got their labels changed. 'We assume knowledge does not decrease so relationships between entities change but do not disappear' (label changes instead of deletions). Only edge counts are used because 'graphs grow by RDF triple units'.  
  source: https://hpc.pnl.gov/people/sinan/publications/al-Saffar_InfValue-iiWAS10.pdf
- [verified] iiWAS 2010 eq (6)-(7): Gc' = Gt UNION Gc; disSimilarity_p(Gc,Gc') = (SUM_{i=1..n} w(e'_i) - SUM_{i=1..m} w(e_i)) / SUM_{i=1..n} w(e'_i), e'_i in Ec', e_i in Ec. Weights: w(e'_uv) = t*degree(v) if u in Gt, v in Vc INTERSECT Vt; w(e'_uv) = t*degree(u) if v in Gt, u in Vc INTERSECT Vt; w(e'_i) = 1 otherwise; t = Trust(Gt,Gc) from eq (8).  
  source: https://hpc.pnl.gov/people/sinan/publications/al-Saffar_InfValue-iiWAS10.pdf
- [verified] iiWAS 2010 Definition 2 and eq (8): 'Trust is the degree of agreement between the target graph, Gt and the consumer's context graph, Gc'; Trust(Gt,Gc) = |Et INTERSECT Ec| / |Et|, Et edges of Gt, Ec edges of Gc; normalised by |Et| 'to account for the number of assertions made by the target document'; asymmetric; example: ten statements, agree with eight => trust 80 percent. 'Trust is necessary but not sufficient'.  
  source: https://hpc.pnl.gov/people/sinan/publications/al-Saffar_InfValue-iiWAS10.pdf
- [verified] iiWAS 2010 eq (9): Impact(Gt,Gc) = SUM_{i=1..n} d_i / SUM_{i=1..m} d'_i, where d_i = degree of v_i in Gc for v_i in Vc INTERSECT Vt, and d'_i = degree of v_i in Gc for v_i in Vc (all context vertices). Motivation: 'If many vertices in Gc have directed edges into a certain vertex, vc overlapping with a vertex, vt in Gt, this indicates a high likelihood of change in Gc'.  
  source: https://hpc.pnl.gov/people/sinan/publications/al-Saffar_InfValue-iiWAS10.pdf
- [verified] iiWAS 2010 eq (10): SIVp = f(Impact(Gt,Gc), Trust(Gt,Gc)), 'where f may be different functions to combine trust and impact in different ways. We use multiplication.' The paper adds that eq (7) 'computed this SIVp based on a particular weights assignment that models trust and impact', i.e. (7) and (10) are two instantiations that are not shown to coincide.  
  source: https://hpc.pnl.gov/people/sinan/publications/al-Saffar_InfValue-iiWAS10.pdf
- [verified] iiWAS 2010 disconnected/cold-start case (Sec 4.2.2): 'If Gt had absolutely no overlapping vertices (entities) with Gc, then Gc will be unchanged in becoming Gc' except for the new disconnected component gained from equation (6). We assign the cost of 1 to the added edges of disconnected components'. Under eq (8) such a candidate has Trust = 0, so eq (10) gives SIVp = 0.
